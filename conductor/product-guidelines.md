# Product Guidelines

## Visual Identity
- **Minimalist Aesthetic:** Prioritize content and readability over decorative elements.
- **Typography:** 
    - Use **Inter** for Latin script to ensure modern readability.
    - Use **Amiri** and **Noto Naskh Arabic** for Arabic script to respect traditional aesthetics while maintaining digital clarity.
- **Color Palette:** Neutral and unobtrusive colors (e.g., whites, grays, and deep blacks) to keep the focus on the text.
- **Responsive Design:** Interfaces must remain functional and clear across all screen sizes (Web UI).

## Communication Style
- **Clarity and Precision:** Error messages and UI labels should be direct and helpful.
- **Academic Tone:** Use respectful and neutral language, suitable for religious and historical data.
- **Developer-Centric API:** API documentation (OpenAPI/gRPC) should be technically accurate and well-structured.

## User Experience (UX)
- **Performance First:** Search and navigation should feel instantaneous.
- **Cross-Platform Consistency:** Maintain a similar logic and feel across CLI, TUI, and Web interfaces.
- **Accessibility:** Ensure high contrast and clear font sizes for a diverse user base.
